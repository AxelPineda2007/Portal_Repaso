## 🛠️ Pila Tecnológica (Tech Stack)

* **Frontend:** HTML5, CSS3 (CSS Grid/Flexbox), JavaScript (ES6+ nativo sin frameworks).
* **Base de Datos & BI:** SQL Server, Microsoft Excel, Power BI, SQLite.
* **Lenguajes & Frameworks:** Python, .NET MAUI, C#, Avalonia UI, Flet, ASP.NET WebForms.
* **Plataformas & Herramientas:** PrestaShop, Odoo ERP, Docker, XAMPP, Jira Service Management.
* **Control de Versiones & IA:** Git, GitHub Pages, Visual Studio Code & IA (Copilot/OpenSpec).

## 💻 Instalación y Uso Local

Si deseas clonar y ejecutar este proyecto en tu entorno local:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/TU_USUARIO/portal-de-repaso.git
   ```
2. **Navegar a la carpeta del proyecto:**
   ```bash
   cd portal-de-repaso
   ```
3. **Abrir el proyecto:**
   Abre el archivo `index.html` en tu navegador o utiliza la extensión **Live Server** en Visual Studio Code.
