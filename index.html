Módulo 3.2 · Mantenimiento y Operación de Sistemas

Prof. Javier Mineros

Investigación profunda sobre el ciclo de vida del software (SDLC), metodologías de soporte técnico, normativas ISO, ITIL 4, SLAs y planes de contingencia (DRP/BCP).

Contenido Detallado:

  • ITIL 4, gestión de servicios y mejora continua.
  • SLAs: acuerdos de nivel de servicio y métricas.
  • Ciclo de vida SDLC y mantenimiento de software.
  • Niveles de soporte, ISO y planes DRP/BCP.
Herramientas: Git, GitHub, Documentación Técnica

Módulo 3.3 · Administración de Bases de Datos

Prof. Javier Mineros

Gestión de bases de datos relacionales, ejecución de consultas SQL complejas, creación de dashboards interactivos en Excel y análisis visual de datos con Power BI.

Herramientas: SQL Server, Microsoft Excel, Power BI, VS Code

Módulo 3.4 · Elaboración de documentación y Apps en Python

Prácticas y Desarrollo

Desarrollo de aplicaciones con Python, integración de sistemas ERP con Odoo, y estructuración de documentación técnica en fases (Fase 1 a Fase 7 / Recuperaciones).

Entregas clave:

  • Aplicaciones con Python y guía individual.
  • Odoo como sistema ERP (Distribuidora Torogoz).
  • Documentación y entregas de las fases 1 a 7.
Herramientas: Python, Odoo ERP, Markdown, GitHub Pages

Módulo 3.8 · Proyecto Innovador de Desarrollo de Software

Prof. Arcides Canales

Desarrollo integral de proyectos de software innovadores, desde la concepción de ideas y documentación hasta los manuales de usuario y sistema, avances periódicos del 10% y 15%, exposiciones y entregas finales.

Contenido detallado y entregas clave:

  • Avances de Proyecto Innovador (10% y 15%).
  • Elaboración de Manual de Sistema y Documentación.
  • Prácticas semanales y exposición de proyectos.
  • Entregas finales y evaluaciones periódicas.
Herramientas: VS Code, Git, GitHub, Documentación Técnica, Metodologías Ágiles
